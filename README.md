# R2R0-TME
scRNA-seq analysis pipeline of post-surgical tumor immune microenvironment in sarcoma murine model

## Overview
This repository contains code and resources used to generate figures from scRNA-seq datasets of a sarcoma murine tumor model investigating immune microenvironment changes following incomplete oncologic resection.
