# R2R0-TME
scRNA-seq Analysis Pipeline of post-surgical tumor immune microenvironment in sarcoma murine model

## Overview
This repository contains code used to generate figure from scRNA-seq analyses of a sarcoma murine tumor model investigating immune microenvironment changes following incomplete oncologic resection. Scripts are organized by manuscript figures. 

## Data Availability

Raw sequencing data are available from GEO under accession: TBD (pending approval). Processed Seurat objects and intermediate matrices are not included in this repository due to size constraints but can be generated using the scripts provided.
